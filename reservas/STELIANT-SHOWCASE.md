# Steliant Reservas — reservas, bots y CRM

Plantilla de exhibición diseñada por **Steliant** para vender un sistema de reservas a barberías, salones y spas. Solo diseño: sin backend ni pagos reales.

- **Inicio**: configurador en vivo (nombre, tipo de negocio y color) con vista previa de la página.
- **Demos**: tres páginas web completas (Barbería, Salón, Spa) con reserva en 4 pasos, depósito con tarjeta 3D y ticket QR; vista escritorio/móvil.
- **Bots**: chat real con el bot (WhatsApp, Instagram, Web) que ofrece horarios, toma el nombre y deja la cita en el panel.
- **Paneles**: Solo, Equipo y Studio con agenda, clientes, equipo, comisiones, bot, reportes y sucursales.
- **Planes**: comparativa, complementos y arranque guiado tras el pago.
- Tema claro/oscuro, ES/EN y responsive.

```bash
cd frontend && npm install && npm run dev
```
