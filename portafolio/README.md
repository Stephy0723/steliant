# Portafolio Steliant

Página principal del portafolio (un solo archivo `index.html`).

- `src/` — código fuente: `data.js` (proyectos, precios, contacto), `i18n.js` (textos ES/EN), `app.js`, `style.css`, `body.html`.
- `bash build.sh` — vuelve a generar `index.html`.
- Datos editables al inicio de `src/data.js`: `CONTACT` (WhatsApp y correo), `PROJECTS`, `PKGS` (precios).

En vivo: https://stephy0723.github.io/steliant/
